# Headless build checks for the A0 split

A0 separates an OSATE-free core (BAST, records, symbols, BLESS3 parser, proof engine and its
tactic grammars) from the AADL front end and the Eclipse UI, so the proof engine can also be
driven from SysML v2 + SFS models. These scripts check that work without starting Eclipse.

| Script | Checks | Passing means |
|---|---|---|
| `compile.sh <out>` | `bless/` (src + xtend-gen), `BLESS-proof/com.multitude.bless.proof/src`, and `com.multitude.bless.codegeneration` compile with `javac` against an installed OSATE's plugins | nothing broke for OSATE |
| `corecheck.sh <out>` | the planned core compiles with **no** `org.osate`, `com.multitude.aadl`, or Eclipse UI on the classpath | the remaining OSATE coupling is zero (it exits non-zero until A0 is finished) |

Both scripts default to `/Applications/osate2.14.0.app/Contents/Eclipse/plugins` and assume
`BLESS-proof` is a sibling of this checkout. To override, set `OSATE_PLUGINS`, `BLESS_IDE`, or
`BLESS_PROOF`.

`shim/` holds a stub of `org.eclipse.xtext.xbase.lib.XbaseGenerated`. It is used only by
`compile.sh`, because `xtend-gen/` was generated by Xtext 2.36+, which is newer than OSATE 2.14's
`xbase.lib`.
